# 동원훈련 Ⅰ형 체험 서버 리소스팩

마인크래프트 26.3 미니게임 서버 "동원훈련 Ⅰ형 체험"에서 쓰는 리소스팩입니다. 서버에 접속하면 자동으로 받으므로 따로 받을 필요는 없습니다.
릴리스 태그 `pack-<sha1 앞 12자리>` 마다 팩 파일 하나(`Dongwon-pack.zip`)가 있습니다.
